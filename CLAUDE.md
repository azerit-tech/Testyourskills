# Testyourskills

Outil de communication pour azerit.tech : une fiche de compétences de dev façon avis de recherche, notée de une à six étoiles, générée depuis un profil LinkedIn, un pseudo GitHub ou un CV.

Lire `SPEC.md` avant toute modification : c'est la spécification cible et la source de vérité pour le design, le jugement et l'ordre de construction. Toute décision qui tranche une question ouverte se reporte dans `SPEC.md`.
